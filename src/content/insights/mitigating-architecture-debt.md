### The Anatomy of Transaction Friction

In corporate carve-outs, the target entity is rarely cleanly decoupled from parent infrastructure. Shared ERP systems, entangled identity providers, and cross-subsidized software licenses create invisible dependencies that prolong TSA periods for quarters beyond expectation.

### The 14-Day Pre-Close Protocol

Black Markt's private equity diligence protocol operates across three concurrent vectors:
- **Codebase Integrity & IP Provenance:** Automated forensic scanning of all core repositories for GPL violations, security vulnerabilities, and developer provenance.
- **Infrastructure Decoupling Complexity:** Dependency mapping of cloud tenancies, shared data pipelines, and third-party SaaS contracts.
- **Team Topology & Key-Person Risk:** Quantitative assessment of commit activity, architecture ownership, and key engineering retainers.
